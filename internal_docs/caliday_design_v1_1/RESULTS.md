## Горо — редизайн базовых поз

Оба файла переработаны для большего сходства с реальной гориллой:

**Голова (общее для idle и flex):**
- Сагиттальный гребень — трёхуровневый (основание / середина / пик), заметно выше
- Надбровные дуги — нависающие с тенью снизу, глаза выглядят «утопленными»
- Морда — отдельный выступающий muzzle-элемент (`muzzleGrad`), прогнатичное строение
- Нос — шире (`rx=54`), ноздри крупнее (`rx=17`)
- Шея — минимальная (горилья пропорция)

**Idle:**
- Руки длиннее, кончики почти касаются земли
- Кисти — 4 knuckle-бугорка, горилья форма
- Ноги короче и компактнее
- Торс — barrel-shape (широкая цилиндрическая грудная клетка)

**Flex:**
- Опорная кисть — knuckle-walking стиль (5 костяшек)
- Бицепс крупнее, с gradient-пиком и едва заметными линиями мышечных волокон
- Флексящий кулак — крупнее с деталями

## Горо — выражения лица (Блок 1 ТЗ)

Все 6 файлов построены на едином шаблоне с идентичными ID слоёв.

| Файл | Триггер в приложении | Ключевые черты |
|------|----------------------|----------------|
| `goro_face_happy.svg` | Тренировка выполнена | Спокойные брови, открытые глаза, широкая улыбка |
| `goro_face_sad.svg` | Вечер, тренировка пропущена | Брови домиком, зрачки вниз, опущенные уголки |
| `goro_face_angry.svg` | Стрик под угрозой | Брови сведены, глаза сужены верхним веком, складка между бровями |
| `goro_face_sleeping.svg` | Ночное время | Глаза закрыты arc-кривыми, приоткрытый рот, zzz |
| `goro_face_excited.svg` | Достижение / новый ранг | Брови высоко, глаза широко, зрачки-звёздочки, открытый рот с зубами |
| `goro_face_supportive.svg` | Возвращение после пропуска | Мягкие брови, нижнее веко приподнято, лёгкая тёплая улыбка |

### Структура SVG-слоёв для Flutter

```
Static (не меняются):
  #layer-bg           — фон + glow
  #layer-head         — голова, гребень, надбровные дуги
  #layer-face-skin    — кожа лица + muzzle
  #layer-ears         — уши
  #layer-nose         — нос, ноздри
  #layer-headband     — повязка

Dynamic (меняются при смене выражения):
  #layer-brows
    #brow-left / #brow-right
  #layer-eyes
    #eye-left-socket / #eye-left-white / #eye-left-pupil
    #eye-left-shine1  / #eye-left-shine2
    (аналогично right)
  #layer-mouth
    #mouth-line-upper / #mouth-curve
    #mouth-fill       / #mouth-lowerlip
```

**Интеграция во Flutter:** переключать SVG целиком через `AnimatedSwitcher` + `flutter_svg`.  
Для плавных морфов — `flutter_animate` с кастомным painter по dynamic-слоям.

## Скала — персонаж Challenge-экрана (Блок 3 ТЗ)

Бык. Строгий судья. Визуально крупнее и монументальнее Горо.

### Цветовая палитра

| Элемент | HEX |
|---------|-----|
| Тело тёмное | `#2E2A22` |
| Тело светлое | `#3D3728` / `#4A4232` |
| Морда | `#6B4F38` → `#8A6848` |
| Рога | `#8B7355` → `#A89060` с highlight `#C8B080` |
| Нос-кольцо (золото) | `#C8A040` / `#E8C060` |
| Фон | `#5C1A1A` → `#3A0C0C` (тёмно-красный) |

### Ключевые детали персонажа

- **Рога** — изогнутые (кривые Безье): уходят широко вбок, загибаются вперёд-вверх с острым кончиком
- **Золотое кольцо в носу** — иконическая деталь, сразу читается
- **Надбровные дуги** — тяжелее чем у Горо, с глубокой тенью; глаза выглядят строгими
- **Фон янтарный** — отличает от синего Горо, создаёт ощущение «другой зоны» (арена испытания)

### Позы

**`skala_neutral_v4.svg`** — руки скрещены на груди, нейтральный взгляд, плотно сжатый рот. «Оценивает молча».

**`skala_approve_v5.svg`** — foreshortened рука с лайком прямо в лицо зрителю:
- Костяшки — вертикальный ряд на правом крае кулака
- Большой палец — толстый, с ногтевой пластиной, вплотную к костяшкам
- Выражение — едва заметная улыбка (уголки рта подняты), судья доволен но не сияет
- Искры — острые 4-лучевые звёзды рядом с большим пальцем
